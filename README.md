# MPV-Subtitle-Downloader
A Subtitle Downloader Powered By Subliminal for MPV Player.
# Instructions
1. Just copy and paste sub_downloader into MPV scripts, or if you use portable_config, portable_config/scripts.
2. Copy this Command into input.conf in order to activate the program: Ctrl+z script-binding open-subtitle-downloader.
   The command is changeable in input.conf.
# Note
Subliminal and PYQT6. I made the program check if you have both on opening. If you don't have, it will suggest to install them automatically. If you have both, it will if yours is outdated and will automatically update both for conveniency.
